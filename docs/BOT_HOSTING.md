## Запуск

1. Создайте Application / Python из архива; файлы приложения должны оказаться в корне рабочего каталога.
2. Выберите главный файл `host.py`. Зависимости в `requirements.txt` отсутствуют намеренно.
3. Токен, ID получателя и пароль панели передайте через закрытые Environment или `.env`, отдельно от публичного архива.
4. Папка `data/` содержит SQLite, пароль и вложения. Восстанавливайте её из согласованной резервной копии до первого запуска. Обновляйте код без перезаписи этой папки.
5. `host.py` слушает `0.0.0.0` на `SERVER_PORT` (или `PORT`). Cookies панели имеют Secure: вход выполняется через HTTPS-домен провайдера.
6. В Domains включите бесплатный поддомен. Проверьте `/api/health`, интерактивное демо и вход в `/admin`.
7. Этот режим использует long polling. Все другие экземпляры с этим токеном должны быть остановлены. Существующий webhook автоматически не удаляется; при его наличии polling останавливается.
8. Проверьте `/resume` в Telegram, создайте заявку, проверьте уведомление и сохранность после перезапуска контейнера при остановленном локальном процессе.

Продлевайте Free каждые 4 дня и храните свою копию данных. Автоматические резервные копии провайдера не заменяют отдельную копию владельца. Не публикуйте приватный архив, `.env` или папку `data/`.
